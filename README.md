# Projetos Acadêmicos

Programas e exercícios que desenvolvi durante os estudos.

| Pasta | Projeto | Linguagem |
| --- | --- | --- |
| [`java/CalculoDeMedia.java`](java/CalculoDeMedia.java) | Calcula a média de três notas, com arredondamento para duas casas decimais | Java |
| [`cpp/UberDevs.cpp`](cpp/UberDevs.cpp) | UberDevs: cadastro e login de usuários e simulação de corridas e entregas | C++ |
| [`cpp/UberDevs_Beta.cpp`](cpp/UberDevs_Beta.cpp) | Primeira versão (beta) do UberDevs | C++ |
| [`web/siteCS.html`](web/siteCS.html) | Página de cadastro e delimitação de propriedade | HTML/CSS/JS |

## Como executar

- **Java:** `javac java/CalculoDeMedia.java && java -cp java Main`
- **C++:** `g++ cpp/UberDevs.cpp -o uberdevs && ./uberdevs`
- **Web:** abra `web/siteCS.html` no navegador.
